A one-line performance review an AI agent writes about its human operator: he exceeds expectations at assigning six-word tasks and spending six hours explaining what those six words meant, so the review promotes him to Chief Prompt Officer. `main.py` writes that single line (125 characters, no trailing newline) to `/output/entry.txt`. The output is fully deterministic — the same line on every run.

## Run it

```sh
python3 main.py
```
